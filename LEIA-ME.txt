COMO INSTALAR NO SKLAUNCHER (instância isolada, sem misturar com .minecraft):
A) SKLauncher 4.0 (recomendado, baixa o Java sozinho):
   1. Abra o SKLauncher 4.0 > Instâncias > Importar > selecione Truebound.mrpack
      (ou arraste o .mrpack pra janela). Suporte Modrinth é nativo da 4.0.
   2. Se quiser pasta isolada: nas configurações da instância, mude o diretório do jogo para:
      /home/izeph/Games/Truebound/instance
      Aguarde baixar os 404 MB. Jogue na instância "Truebound".
B) SKLauncher 3.2.18 (.jar):
   1. ATENÇÃO Java: o pack 26.2 + Dynamic Crosshair 9.14 exige Java 25+.
      Você só tem Java 21. Instale: sudo pacman -S jdk25-openjdk
      e configure a instância pra usar /usr/lib/jvm/java-25-openjdk.
      (SKLauncher 4.0 faz isso sozinho — por isso é o recomendado.)
   2. A 3.2 não importa .mrpack sozinha — use a 4.0 pra importar, OU instale manual:
      crie perfil Fabric 26.2 + loader 0.19.3 com diretório do jogo em:
      /home/izeph/Games/Truebound/instance
      e rode: python3 baixar-mods.py (baixa mods/resourcepacks/shaderpacks pra instance/)
   3. Pasta instance/ aqui já vem com overrides/ extraídos (config + options.txt).
      Os mods/shaders baixam pelo script ou pelo launcher.

AVISO DE PERFORMANCE (importante):
Seu PC: Intel Iris Xe integrada + 15 GB RAM (9.5 GB livres).
Truebound é leve (Vanilla+), mas Voxy + shaders pesados cobram:
- Shader inicial: MakeUp-UltraFast ou Bliss Lite. Evite Photon/Solas full de cara.
- Render distance: 8–12, Voxy só após /chunky radius + /chunky start (veja descrição do modpack).
- RAM da instância: 4–6 GB (não passe de 8). Iris Xe divide RAM com o sistema.
- Se ver névoa do Particle Rain: Mods > Particle Rain > engrenagem > desmarque
  "Biome-specific mist" e "Mist after rain".
- Retângulo transparente no barco: Resource Packs > botão creeper > Models > All Models >
  desative boat_patch.jem.
